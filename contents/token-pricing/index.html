PricingAI サービスのトークン単価

LLM を API で使うと、読ませた文章と書かせた文章の量に応じて料金がかかります。量は「トークン」という単位で数えます。トークンは単語や文字のかけらです。OpenAI は2021年の料金ページで、1,000トークンを英語のおよそ750語分と説明していました。各社が公開しているトークン単価を1つの表にまとめ、2020年の GPT-3 からの推移も図にしました。月額制のサブスクリプションとの比べ方も載せています。

Now現在のトークン単価

100万トークンあたりの米ドルです。入力は読ませた分、出力は書かせた分の単価です。キャッシュ入力は、前と同じ入力をくり返し送ったときに安くなる分の単価です。

Subscriptionサブスクリプションと比べる

ChatGPT や Claude などの月額制のプランは、使った量ではなく月額で払います。上限の多くはトークン数ではなく「Pro の5倍」のような書き方で示されているため、1トークンあたりの単価には直せません。そこで、月額が API なら何トークン分にあたるかを目安として出しました。

月額が API で何トークン分にあたるか

入力と出力の比を 3:1 と仮定した平均の単価で割っています。月にこれより多く使うならサブスクリプションが、少ないなら API が割安という目安です。

単位は「万トークン」です。API の単価は上の表の値です。チャットでは会話が長くなるほど入力が増えるので、実際の比は使い方で大きく変わります。

主なプランの月額と上限の書き方

提供元とサービス プラン 月額（月払い） 上限の書き方（公式の記述の要約） API との関係

月額は米ドルの月払いの価格です。日本円の価格が公式に出ているものは、月額の下に元の表記のまま載せました。年払いの割引や税の扱いはプランごとに違います。上限の書き方は公式の記述を短くまとめたもので、詳しくは各プランの出典を見てください。

Japan国内の LLM API

国内の事業者の LLM は、単価を公開していないものが多くあります。公開しているものは元の表記（円など）のまま載せ、米ドルには換算していません。

Notes読み方の注意と参照先

  • トークンの数え方はモデルごとに違います。同じ日本語の文でも、モデルによってトークン数が変わります。単価だけで実際の料金は比べられません。
  • 推論モデルが答えの前に内部で考えた分も、多くの場合は出力トークンとして課金されます。
  • キャッシュ、まとめて処理する Batch の割引、長い入力の割増、無料枠などの条件で、実際の料金は変わります。条件は表の注記に書きました。
  • 税は含みません。円や人民元の単価は米ドルに換算していません。
  • 1000トークンあたりで公開されていた時代の単価は、100万トークンあたりに直しました。元の表記は推移の表に残しています。
  • 2026年11月27日時点の情報です。
